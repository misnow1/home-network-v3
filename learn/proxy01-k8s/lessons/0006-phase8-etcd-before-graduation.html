Lesson 0006 · Beyond the edge

Phase 8/9 bridge — etcd before graduation

One idea: the hybrid edge is boring now — so the runbook raises the bar. A useful app waits until you can snapshot (and eventually restore) etcd.

Why this matters for your mission

Lessons 0001–0005 made Internet → proxy01 → VIP → Gateway → app real. Work clusters treat control-plane backup as non-optional before anything you would mourn. ADR 003 and Phase 8 say the same: do not deploy Uptime Kuma (or other useful apps) until a snapshot restore drill succeeds.

Knowledge — what etcd is (and is not)

  • etcd holds cluster state: API objects, whoami Deployment/Service/HTTPRoute, Gateway config, Secrets metadata, etc.
  • PVC data (Uptime Kuma DB, future NFS volumes) is not in etcd. Phase 8 protects the control plane; Velero/PVC backup is a later milestone.
  • PKI under /etc/kubernetes/pki must travel with snapshots — restore without certs is a different kind of pain.
Before Phase 9 ───────────────────────────── ✓ hybrid edge (you did this) ✓ whoami disposable smoke app □ etcd snapshot on k8s-cp01 □ copy snapshot + pki off-box □ restore drill (lab or documented) □ then Uptime Kuma + PVC + drain test

Manual snapshot (Phase 8 skill)

Install the CLI first — kubeadm does not ship etcdctl on the host: sudo apt-get install -y etcd-client on control-plane nodes (runbook Phase 8).

On k8s-cp01:

sudo ETCDCTL_API=3 etcdctl snapshot save /var/backups/etcd-$(date +%F).db \
  --endpoints=https://127.0.0.1:2379 \
  --cacert=/etc/kubernetes/pki/etcd/ca.crt \
  --cert=/etc/kubernetes/pki/etcd/server.crt \
  --key=/etc/kubernetes/pki/etcd/server.key

# Then copy off-box (kif restic scope or rsync), including /etc/kubernetes/pki

Upstream mental model: Backing up an etcd cluster (kubeadm uses stacked etcd on the CP; same etcdctl snapshot tool).

A file on the CP disk is not a backup. Off-box copy is part of “done.” Scheduling (cron/systemd timer) comes after a manual save works once. Safe verify (restore to a throwaway data-dir) proves the file; full cutover is still required before graduation apps — see runbook Phase 8.

Phase 9 — what “graduation” reuses

Uptime Kuma (or similar) is the same Phase 7 ceremony plus durability:

  • HTTPRoute + proxy01 auth_required (lessons 0002–0003)
  • PVC on local-path or NFS StorageClass
  • Drain one worker; confirm the pod lands on the other

Skill — clear the backup bar (first step)

This lesson’s win is a verified snapshot file off the CP, not a full disaster recovery yet. Restore drill is the next practice session (use lab if you do not want to risk prod CP).

  1. SSH to k8s-cp01; ensure /var/backups exists and is writable by root
  2. Run etcdctl snapshot save …; confirm non-zero file size
  3. etcdctl snapshot status <file> -w table (sanity)
  4. Copy .db + note path to pki tarball/rsync target off-box
  5. Write one sentence in your notes: where the copy lives and the date
