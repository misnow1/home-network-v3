Phase 7 site checklist

Print-friendly. One public k8s hostname through proxy01.

Four-name contract

DNS ─────────────► proxy01 public IP
certbot_domains ─► same FQDN on SAN cert
server_names ────► reverse_proxy_sites
HTTPRoute hostnames ► Envoy Host match

Site YAML skeleton

- name: app.example.com
  server_names:
    - app.example.com
  locations:
    - path: /
      proxy_pass: http://192.168.9.200
      auth_required: true   # location-scoped
      rate_limit:
        zone: proxied_apps
        burst: 20

Apply (production)

./scripts/prod-run.sh --confirm-production -- \
  playbooks/certbot.yml --limit proxy01… -e allow_production=true

./scripts/prod-run.sh --confirm-production -- \
  playbooks/reverse-proxy.yml --limit proxy01… -e allow_production=true

Verify

# LAN / VIP
curl -sS -H 'Host: app.example.com' http://192.168.9.200/

# Public edge
curl -sS -I https://app.example.com/
# 302/401 Authelia = path alive; 502 = Gateway/VIP; timeout = firewall
