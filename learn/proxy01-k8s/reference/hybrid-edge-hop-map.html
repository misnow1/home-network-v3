Hybrid edge hop map

Compressed path for Phase 7. Print-friendly.

Internet :443 │ ▼ proxy01 nginx TLS terminate + Authelia forward-auth upstream = http://192.168.9.200 │ VLAN 1 → 9 (firewall must allow) ▼ MetalLB VIP 192.168.9.200 (pool .200–.210) L2 ARP on VLAN 9 one speaker node owns the MAC answer │ ▼ Envoy Gateway Service type LoadBalancer Gateway listener :80 HTTP only (TLS stays on proxy01) │ ▼ HTTPRoute match Host (+ path) → Service:port │ ▼ Pods

Who owns what

  • proxy01 — public TLS, certbot, Authelia, rate limits
  • MetalLB — VIP assignment + ARP advertisement
  • Envoy Gateway — Gateway API implementation (L7 proxy)
  • HTTPRoute — per-app Host/path → Service (like server_name)
