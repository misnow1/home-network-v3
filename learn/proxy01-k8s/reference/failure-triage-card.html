Failure triage card

Print-friendly. Start at the top; stop at the first broken hop.

Decision order

  1. From proxy01: curl -m5 -sS -o /dev/null -w '%{http_code}\n' http://192.168.9.200/
  2. Same with -H 'Host: <public-name>'
  3. kubectl get svc -n envoy-gateway-system — EXTERNAL-IP = VIP?
  4. kubectl get gateway,httproute -A then describe httproute
  5. Backend pods Ready? Service port name matches backendRefs?

Symptom → hop

timeout          → firewall VLAN 1→9 / MetalLB ARP / VIP pending
502              → Envoy / Gateway / backends (not Authelia first)
404 + good Host  → HTTPRoute host/path; Host header rewrite
Accepted=False   → allowedRoutes, parentRefs, ports, ReferenceGrant
302/401 Authelia → edge auth rules (VIP path may still be fine)

Runbook anchors

  • MetalLB VIP unreachable from proxy01
  • Gateway 502 from proxy01
  • HTTPRoute Accepted=False
