Reference

ReferenceGrant card

Print-friendly. Two handshakes, one grant shape.

When you need it

HTTPRoute.backendRefs.namespace != HTTPRoute.metadata.namespace
  → ReferenceGrant required in the Service’s namespace

HTTPRoute → Gateway in another NS
  → Gateway.spec.listeners[].allowedRoutes
  → (not ReferenceGrant)

Skeleton

apiVersion: gateway.networking.k8s.io/v1beta1
kind: ReferenceGrant
metadata:
  name: allow-from-edge
  namespace: <service-ns>
spec:
  from:
    - group: gateway.networking.k8s.io
      kind: HTTPRoute
      namespace: <route-ns>
  to:
    - group: ""
      kind: Service

Verify

kubectl -n <route-ns> describe httproute <name>
# Want: ResolvedRefs=True

kubectl -n <service-ns> get referencegrant
