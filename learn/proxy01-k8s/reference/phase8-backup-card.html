Phase 8 backup card

Print-friendly. Snapshot → off-box → then graduation apps.

Protects / does not

etcd snapshot  → API objects, cluster config
pki copy       → /etc/kubernetes/pki (with snapshot)
NOT covered    → PVC bytes (Kuma DB, NFS data)

Prerequisite

sudo apt-get install -y etcd-client   # CP hosts; not pulled in by kubeadm

Manual save (k8s-cp01)

sudo mkdir -p /var/backups
sudo ETCDCTL_API=3 etcdctl snapshot save /var/backups/etcd-$(date +%F).db \
  --endpoints=https://127.0.0.1:2379 \
  --cacert=/etc/kubernetes/pki/etcd/ca.crt \
  --cert=/etc/kubernetes/pki/etcd/server.crt \
  --key=/etc/kubernetes/pki/etcd/server.key

sudo ETCDCTL_API=3 etcdctl snapshot status /var/backups/etcd-*.db -w table
# Prefer: etcdutl --write-out=table snapshot status …
# rsync/scp .db + pki off-box (e.g. kif /archive/backup/)

# then rm -rf it. Never edit etcd.yaml for this drill.
